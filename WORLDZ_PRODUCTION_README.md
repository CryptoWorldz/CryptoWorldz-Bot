# Worldz Production Suite

A single static, hostname-aware website engine for the OneWorldz and CryptoWorldz ecosystem.

## Supported destinations

- OneWorldz.com
- CryptoWorldz.xyz
- SolWorldz.xyz
- EthWorldz.xyz
- XRPWorldz.xyz
- BaseWorldz.xyz
- BNBWorldz.xyz
- SuiWorldz.xyz
- HyperWorldz.xyz
- RobinWorldz.xyz
- BitWorldz.xyz / BitcoinWorldz.xyz
- HodlerWorldz.xyz
- PurpleDiamondCrew.com
- impact.oneworldz.com
- law.oneworldz.com
- learn.oneworldz.com
- cryptobotz.cryptoworldz.xyz (public Zed portal only; backend remains separate)

## Preview

Use `?site=solworldz&preview=1` or another site key to preview every identity from one deployment.

## Hostinger deployment

Connect each Custom PHP/HTML site to the same GitHub branch and deploy to an empty `public_html` directory. Hostname detection automatically loads the correct site identity.

## Safety

No contract addresses, token prices, market caps, launch dates, liquidity figures, partnerships or donation totals are invented. Empty data displays as not yet verified or coming soon.
