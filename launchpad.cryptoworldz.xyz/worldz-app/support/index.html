WorldzApp™ Support

This page is the first-party support surface for the WorldzApp release pipeline.

Before requesting help

  • Record your WorldzApp version/build and Android version.
  • Describe the screen, chain and wallet provider involved.
  • Include a public transaction hash only when it is relevant.
  • Never send a seed phrase, private key, recovery phrase, wallet password or exported signing key.

Release support contact

During pre-release, the WorldzApp developer account is being established with jayjayteamdev@outlook.com. A dedicated public WorldzApp support address remains a release gate and will be published here and in Google Play before submission.

Current authority boundary

WorldzApp currently provides public/read-oriented and review functionality under explicit gates. Approval submission, transaction signing, execution and mainnet broadcast remain disabled unless a later verified release explicitly enables them.

Privacy

Read the WorldzApp Privacy Notice for the current data-handling boundary.
