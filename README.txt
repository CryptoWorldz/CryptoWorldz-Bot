CRYPTOWORLDZ SHARED WORLDZ ENGINE

This single custom HTML package renders a different Worldz website based on the visitor's domain.
Included domain profiles:
- solworldz.xyz
- ethworldz.xyz
- xrpworldz.xyz
- baseworldz.xyz
- bnbworldz.xyz
- suiworldz.xyz
- hyperworldz.xyz
- robinworldz.xyz
- bitworldz.xyz / bitcoinworldz.xyz
- hodlerworldz.xyz

Preview locally by adding ?site=solworldz, ?site=baseworldz, etc.

Recommended deployment after owner approval:
1. Create one empty Custom PHP/HTML website in Hostinger as the Worldz Engine host.
2. Upload this package once.
3. Park/mirror each chain domain to the engine host.
4. The browser keeps the requested domain, and app.js selects the matching content.
5. Keep CryptoWorldz.xyz, OneWorldz.com, and PurpleDiamondCrew.com as separate specialist websites.

Do not deploy until final links and branding are approved.
