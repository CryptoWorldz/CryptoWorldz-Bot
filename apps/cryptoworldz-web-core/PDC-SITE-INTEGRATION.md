## Three-page experience

PurpleDiamondCrew.com now routes to a dedicated three-section website instead of presenting Purple Diamond Crew as only a retired-token directory.

- BBQs and food support
- Backpacks and essential packs

- Apply to help on the ground
- Contribute supplies or discuss support
- Suggest projects
- Propose partnerships
- Connect through the canonical Purple Diamond Crew X and Telegram channels
- Route larger future initiatives into ImpactBased and OneWorldz

Donation links are not displayed until the destination, receiving account and stated purpose are verified.

### Page Three — The OneWorldz Hope Chest

The supplied OneWorldz Hope Chest artwork is the verified full-page background for the secret legacy vault.

The vault displays the ten verified Purple Diamond Crew token records as translucent cards in two desktop rows of five. Selecting a card opens its verified contract, status, project information and available public links.

The page includes the hint:

> If only some things could be new again...

An `Invest` action is displayed only when a verified trade or DEX URL exists. A launch-page or explorer action is shown otherwise.

## Hope Chest asset security

The optimized background is stored in the RLS-protected `site_assets` registry under the slug `pdc-hope-chest`.

- Public browser roles have read-only access to public assets.
- Public browser roles cannot insert, update or delete assets.
- The frontend validates the `data:image/jpeg;base64,` prefix before applying the image.
- The stored image decodes to 13,722 bytes with JPEG header `ffd8ffe0`.
- The stored base64 SHA-256 is `ea4a5ff5bed5b03a46be1d3efceb55e18a9274fc25b08971607794bde3fcfe3c`.
