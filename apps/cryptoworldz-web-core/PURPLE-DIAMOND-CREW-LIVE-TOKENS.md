# Purple Diamond Crew Live Token Hub

## Locked role

`purplediamondcrew.com` becomes the public home for existing CryptoWorldz ecosystem tokens that are already live.

It is not the launchpad for new contracts. New launches flow through ImpactBased / Based.bid, then appear on CryptoWorldz and their relevant blockchain World site after verification.

## Page purpose

The Purple Diamond Crew site will provide:

- a live-token directory
- token name, symbol and blockchain
- verified contract address
- DEX Screener chart and trading link
- official project and social links
- impact or community purpose
- clear risk and verification notices

Only records with `launch_status = live` should appear in the live-token directory.

## Current hosting rule

Keep the existing `purplediamondcrew.com` website untouched until its current content is backed up. Then replace or update it using the shared CryptoWorldz registry.

## Existing-site safety

Do not delete or overwrite:

- `cryptobotz.cryptoworldz.xyz`
- `cryptoworldz.xyz`
- `purplediamondcrew.com`
- `solworld.fun`

until each site has been backed up and its final replacement or redirect has been confirmed.
