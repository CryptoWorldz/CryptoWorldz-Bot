## Authority

This recovery follows the approved 13 August 2026 OneWorldz Master Build Specification and the existing OneWorldz architecture. It does not introduce a new brand direction.

## OneWorldz role

`OneWorldz.com` is the global gateway: **OneWorldz 🌏 One Vision** and **Helping the People Who Help People**.

It must present the original One Vision structure:

1. Vision
2. Mission
3. Core Principles
4. Four Pillars — People, Planet, Technology, Leadership
5. Global Research Network
6. Research → Compare → Verify → Recommend → Implement → Measure Results → Improve Again
7. Community Participation
8. Global Areas of Focus
9. Measuring Success
10. Long-Term Goal

Humanitarian action remains central. Crypto detail stays primarily under CryptoWorldz rather than overwhelming the OneWorldz gateway.

6. Every destination link is verified before release; unresolved destinations are not represented as successfully live.
7. Desktop and mobile visual proof is required before production approval.
8. The 17-target deployment workflow is not triggered by this branch.

## Production gate

This branch is for recovery/build/proof only. Production remains separately gated. No live deployment is performed merely because this recovery file exists.
