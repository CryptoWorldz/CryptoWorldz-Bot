# PurpleDiamondCrew Production Contract

PurpleDiamondCrew.com follows the standalone Worldz deployment standard.

1. The domain owns its own static bundle and document root.
2. The Action Team, Crew, and Hope Chest pages must all pass verification before deployment.
3. Required artwork uses built-in SVG so a missing remote image cannot blank a production section.
4. The verified `pdc-hope-chest` master is an enhancement over the built-in chest, never the only visual.
5. All ten Hope Chest token records retain a built-in visual fallback. Historical token logos are optional enhancements only.
6. Legacy token records are archive material, not current-launch claims or endorsements.
7. Production HTML is no-cache.
8. Deployment requires the exact `PURPLEDIAMONDCREW.COM` guard, a domain-only FTP account, rollback capture, upload, and live verification.
9. Zed and Auto services are outside the PurpleDiamondCrew static document root and must remain untouched.
