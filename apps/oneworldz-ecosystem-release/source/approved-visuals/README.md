Production image law:
- The Master Reference Library is reference-only and is never deployed as live website artwork.
- Use only separately approved generated production masters as visual source material.
- Never substitute, copy, or directly publish a Reference Library file or screenshot.
- Build separate desktop and mobile production assets for the real website containers.
- Preserve natural proportions; never stretch, blur, randomly crop, or upscale beyond the approved source.
- Desktop production render: web-optimised AVIF, maximum width 1920px.
- Mobile production render: separate web-optimised AVIF, maximum width 960px.
- Desktop and mobile production files must have different byte hashes; copying the same file into both responsive paths is prohibited.
- The approved generated master remains source-only and is not shipped as a public production asset.
- Every responsive render must pass the browser visual proof at its actual desktop and mobile viewport before deployment.
- Production deployment remains a separate gate after the new responsive candidate passes verification.
