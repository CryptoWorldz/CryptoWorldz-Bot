# SolWorldz.xyz Website

This branch records the standalone SolWorldz master website created directly by ChatGPT without Hostinger Horizons credits.

## Deployment

The current preview is deployed through the existing CryptoWorldz Supabase project as the public Edge Function `solworldz-site`.

## Source package

The complete static deployment package contains:

- `index.html`
- `assets/styles.css`
- `assets/config.js`
- `assets/app.js`
- reusable SVG branding assets
- privacy, terms and community-guidelines pages

The design is mobile-first and uses a central World configuration so it can be adapted for EthWorldz, XRPWorldz, BaseWorldz and future blockchain Worldz.

## Safety

This branch is isolated from `main` so the live CryptoWorldz Zed Bot remains unchanged.
