Turn wallet clutter into useful choices.

Spam2Ham is now researching the wallet side too. The rule is simple: we never pretend a worthless token magically becomes money. We first find out what the wallet actually owns, what is safe to leave alone, what may have a real market route, and what token accounts may be eligible for safe cleanup.

Important: receiving an unknown token does not by itself compromise your wallet. If we cannot establish a safe action, the default answer is IGNORE / HIDE — not “click it and hope.” The scanner below reads public blockchain data only. It does not connect your wallet, sign anything, open token links, burn anything or move funds.

Two brains are better than one

HAM Node Mesh™

The safest version is not one giant bot with permission to do everything. Each node gets one job, a narrow permission boundary and proof before handing work to the next.

NODE 01

Inventory Node

Solana RPC discovers token accounts, balances, program type and account lamports. Public wallet data only.

NODE 02

Trust + Market Node

Jupiter verification, organic score, holders, liquidity and audit signals add context. No single score gets to decide “safe.”

NODE 03

Route + Value Node

A displayed price is not enough. Future salvage requires a fresh executable quote, minimum output, slippage and fees.

NODE 04

Safe Execution Node

Inspect Token-2022 extensions, allow-list instructions, simulate the transaction, display every destination, then ask the wallet to sign.

NODE 05

Worldz Choice Router

Cleanup finishes first. Only then can the user separately choose KEEP, WORLDZ, DONATE, SHARE or CHRISTMAS.

NODE 06

Proof Node

Confirm the transaction and produce a plain-English receipt showing what was burned, closed, swapped, kept or redirected.

Safety first

Clean it. Don’t engage with it.

Never click an unknown link or open a suspicious attachment just to “clean” it. ACMA advises using unsubscribe facilities for organisations you recognise, but not clicking message links when you cannot verify the sender. Suspected commercial spam and scams have different reporting pathways.
ACMA — Dealing with Spam Scamwatch — Report a Scam

Official reporting is for genuine concerns. Spam2Ham does not award HAM Points for the number of reports or complaints made.
