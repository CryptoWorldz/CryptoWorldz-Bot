# WorldDexPush™ × DEX Screener — WorldzSpecial Proposal

Status: **proposal draft — no partnership or endorsement claimed**

## Purpose

WorldzLaunchPad is building WorldDexPush™, a transparent post-launch identity and market-discovery layer. We would like to explore whether DEX Screener is open to a custom **WorldzSpecial** integration/package for WorldzLaunchPad projects.

## What Worldz would provide

- Canonical token identity packages: name, ticker, image, website, socials, chain and contract/mint.
- Exact pool/pair addresses and Worldz Proof Receipt™ records.
- Public separation between free automatic indexing, paid Enhanced Token Info, Boosts and any custom advertising.
- No fake verification badge and no claim that DEX Screener endorses a project.
- Explicit user approval before any provider purchase.

## What we would like to discuss

1. A documented WorldzLaunchPad → DEX Screener post-launch handoff.
2. A way to direct creators to the correct official Enhanced Token Info / Boost flow from WorldDexPush™.
3. Whether a custom Worldz-branded package, campaign or integration is commercially available.
4. Whether DEX Screener can provide an approved machine-readable status signal for purchases/profile updates so Worldz Proof can show provider-confirmed state.
5. Any requirements WorldzLaunchPad should enforce before directing a creator to DEX Screener.

## Golden Ticker rule

Worldz will use DEX Screener's published requirement rather than inventing its own threshold. The current WorldDexPush configuration records **500+ active Boosts** as the Golden Ticker threshold.
