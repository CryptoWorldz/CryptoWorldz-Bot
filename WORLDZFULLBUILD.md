## Project inheritance rule

WorldzFullBuild™ inherits project-relevant decisions, corrections, requirements, lessons and approved concepts from the Worldz project and its chats.

Precedence:

1. Current explicit JayJayTeamDev instruction.
2. Canonical WorldzFullBuild / token / deployment contracts.
3. Confirmed live or on-chain evidence.
4. Current repository implementation.
5. Project files and approved source records.
6. Older project-chat plans and research.

Conflicts are reconciled deliberately. Superseded values are not merged into newer values just to make both appear true.

## Privacy boundary

WorldzFullBuild™ absorbs **project requirements**, not unrelated private life material. Public build files must not copy private medical, legal, credential, secret-key, seed-phrase, private financial or unrelated personal chat content.
